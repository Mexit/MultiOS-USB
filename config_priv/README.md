You can store your custom configurations in this directory. They will not be deleted during automatic MultiOS-USB updates.

The `examples` directory contains sample configurations. To use one, copy the desired file to `config_priv` and adapt it to your needs.

Once you have created a new configuration or modified an existing one, you can submit your changes to the repository and share your configuration here:
https://github.com/Mexit/MultiOS-USB/issues
